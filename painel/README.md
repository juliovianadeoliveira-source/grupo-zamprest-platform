# Grupo Zamprest — base de aplicação

Este diretório prepara o primeiro bloco funcional com autenticação Supabase, empresas por proprietário, cadastro de clientes e agenda. Não está conectado a nenhum banco e não altera a publicação atual.

O banco deve ser escolhido antes de instalar `schema.sql`; o arquivo `config.example.js` descreve as variáveis públicas do frontend. Nenhuma chave privilegiada deve ser incluída no repositório. Antes da publicação, testar autenticação, isolamento entre contas, inclusão/exclusão e as políticas de acesso.

As integrações de WhatsApp, conversas, técnicos, IA e permissões para equipes ainda precisam ser especificadas e implementadas. O código atual não afirma oferecer esses recursos.
